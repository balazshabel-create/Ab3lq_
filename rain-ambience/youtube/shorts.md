# Shorts / TikTok / Reels clips

Three vertical clips (1080×1920, 30 fps). Each one promotes the full 1-hour video. Post them 1–2 days apart. On YouTube, link each Short to the long video with **"Related video"** (YouTube Studio → Short → Related video).

|---|---|---|

## Tips

- **Loop-friendly:** the clips fade in and out quietly, so viewers often watch them twice, which TikTok counts as strong retention.
- **TikTok sound:** post with the original sound, and name it something like "Rain on window for sleep". Then other creators can use your sound, which spreads the clip.
- **Posting time:** 21:00–23:30 local time, when sleep content performs best.
